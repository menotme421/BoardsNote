Ink·Frame Documentation

Welcome to the official documentation for Ink·Frame, your minimalist workspace for notes and ideas.

Getting Started

Ink·Frame is designed to be intuitive and fast. You can create two types of files: Notes for writing and Canvas for visual thinking.

Slash Commands

In the note editor, type / to reveal the command menu. This allows you to quickly insert headings, tables, images, and more without leaving your keyboard.

Keyboard Shortcuts

Use the following shortcuts to speed up your workflow:

  • Cmd + K: Open Command Palette
  • Cmd + N: New Note
  • Cmd + Shift + N: New Canvas
  • Cmd + \: Toggle Sidebar

Customization

You can change the font of each note individually using the font picker in the top bar. Choose between Default, Professional, Literary, Technical, and Focus fonts to suit your content.
